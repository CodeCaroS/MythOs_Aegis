# Optimizer Meta Memory

- A small shared profile declaration improved structural output coverage while
  preserving domain guidance.
- Composition profiles work better than one universal template because artifact,
  decision, execution, research, plan, review, and status outputs have different
  valid shapes.
- Keep the component library responsible for generic ordering and honesty rules;
  keep domain fields in the owning skill.
- Do not infer runtime behavior from a static contract score. Final reporting must
  label these evaluations as synthetic output-contract projections.
- Future runs may test selective deletion of legacy duplicated templates, but only
  with per-skill rollout evidence and a fresh held-out test split.
