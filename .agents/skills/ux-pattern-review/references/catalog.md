## Review section checklist

For each applicable pattern, review every section the current page provides:

- Use cases and avoid cases.
- Benefits, drawbacks, and credible alternatives.
- Required and optional anatomy.
- Variations and content guidance.
- Visual, layout, and interaction best practices.
- State management, errors, API behavior, and performance.
- Accessibility, localization, analytics, SEO, and design tokens when relevant.
- Functional, accessibility, responsive, and edge-case testing.
- Related patterns, FAQs, and source limitations.
